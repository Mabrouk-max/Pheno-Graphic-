Pheno Graphic — site web

## Mise en ligne avec GitHub Pages

1. Crée un dépôt public nommé `pheno-graphic`.
2. Ajoute `index.html`, `style.css` et `script.js`.
3. Dans `script.js`, remplace `226XXXXXXXX` par ton numéro WhatsApp.
4. Dans GitHub : Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
5. Ton site sera accessible depuis l'adresse GitHub Pages fournie par GitHub.

## Personnalisation

- Les couleurs principales sont le noir et le rose.
- Modifie les textes directement dans `index.html`.
- Les exemples du portfolio sont des visuels graphiques intégrés : remplace-les plus tard par tes propres images.
